# Sistema de documentos do projeto

Estes arquivos coordenam o desenvolvimento do pacote em conversas separadas
(chat-ponte orquestrador + chats-filho executores). Versionados aqui para
histórico e para que qualquer conversa nova possa ser inicializada a partir do
repositório.

| Arquivo | Conteúdo |
|---|---|
| `00_README_Orientacao.md` | Como o sistema multi-chat funciona |
| `01_Briefing_Mestre.md` | Contexto do projeto e decisões de fundação |
| `02_Fases_Briefing.md` | Briefing de cada uma das 11 fases |
| `03_Estado_Projeto.md` | Estado corrente — **documento vivo** |
| `04_Template_Handoff.md` | Formato do handoff de fase |

Comece por `00_README_Orientacao.md`.
